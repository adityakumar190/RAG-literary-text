Abstract

This project explores the extraction of Indian cultural elements, with particular attention to flora and fauna, from Indian literary texts. A repository of literary texts is used as the source collection, and a Retrieval-Augmented Generation (RAG) workflow supports the identification of relevant passages and the extraction of plant and animal names. The extracted results are organised in a Python file named flora_fauna.py, with separate collections for flora and fauna. The Python file is published in a GitHub repository and linked from this project webpage.

1Introduction

Indian literary texts contain references to plants, trees, flowers, crops, animals, birds, reptiles, fish and insects. Such references can communicate information about the natural environment as well as cultural practices, symbolism, everyday life and regional knowledge.

This project uses Retrieval-Augmented Generation (RAG) to work with a collection of Indian literary texts and identify references to flora and fauna. The extracted terms are organised systematically so that the results can be inspected, reused and extended.

2Objectives

  1. To create a repository of Indian literary texts selected for the assignment.

4Method

The work follows the RAG-based process demonstrated in class. The main stages are:

  1. Text repository: Collect and organise the six Indian literary texts in a digital repository.
  2. Preparation: Prepare the text data for processing, including splitting it into suitable passages or chunks.
  3. Retrieval: Retrieve passages relevant to queries about plants, trees, flowers, crops, animals, birds and other fauna.
  4. Extraction: Examine the retrieved passages and record the flora and fauna terms supported by the texts.
  5. Organisation: Arrange the extracted terms in the required Python lists, flora_RAG_extraction and fauna_RAG_extraction, in flora_fauna.py.
  6. Publication: Upload the Python file to GitHub and link to it from this webpage.

7Observations

The extracted references can be examined to identify recurring plants and animals, distinctive references associated with individual texts, and the ways in which the natural world appears in literary descriptions. A comparison across the six texts may also show differences in setting, imagery and cultural context.

  • Recurring references: Note flora or fauna terms that occur in more than one text.
  • Text-specific references: Identify terms that appear in only one source text.
  • Cultural significance: Where supported by the passage, discuss symbolic, religious, agricultural or everyday associations.
  • Source traceability: Keep track of the text and passage from which each extracted term was identified.

8Limitations

  • Some references may be ambiguous, metaphorical or used as proper names rather than literal references to flora or fauna.
  • Older literary texts may use historical, regional or variant spellings for plant and animal names.
  • Some terms may refer to broad groups rather than identifiable species.
  • Automated retrieval and generation may miss relevant references or suggest terms that require verification against the original passage.
  • Each extracted item should therefore be checked against its source text before it is included in the final dataset.

9Conclusion

This project applies a RAG workflow to the study of Indian literary texts and the extraction of flora and fauna references. The results are organised in the prescribed Python file, flora_fauna.py, and made accessible through a GitHub repository and this webpage. The resulting collection provides a structured starting point for examining representations of the natural world in Indian literary writing.
